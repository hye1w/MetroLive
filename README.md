# 지하철 라이브 (SeoulMetroLive) — M1

서울 지하철 실시간 안내 개인용 앱. 설계서 v0.2 기준 M1 구현.

## 빌드 방법 (Android Studio)
1. Android Studio 최신 버전으로 이 폴더 열기 (Gradle 자동 동기화)
2. **개인 키 없이 바로 빌드 가능** — `local.properties`를 만들지 않으면 자동으로 `SEOUL_API_KEY=sample`
   (열린데이터광장 공용 샘플키, 응답 **최대 5건 제한**)으로 빌드됩니다. 동작 확인용으로 우선 이 상태로 실행하세요.
   - 화면 상단에 "샘플키 모드" 배지가 뜨면 정상입니다.
3. 나중에 개인 키를 발급받으면 `local.properties.example` → `local.properties` 복사 후 `SEOUL_API_KEY` 입력
   - 키 발급: https://data.seoul.go.kr 또는 https://www.data.go.kr
4. 폰 연결(USB 디버깅) 후 Run ▶ — 또는 Build > APK 생성 후 설치

### 샘플키로 확인할 수 있는 것 / 없는 것
| 확인 가능 | 제한됨 |
|---|---|
| 앱 빌드·설치·화면 전환 정상 동작 | 실시간 응답이 최대 5건이라 원하는 열차가 누락될 수 있음 |
| API 연결·JSON 파싱 파이프라인 | 도착 카운트다운(`--:--`)이 안 뜰 수 있음(매칭 열차 없을 때) |
| recptnDt 시차 보정 로직 동작 | 세션 알림 등 일부 흐름은 데이터 누락 시 부정확 |
| 노선도·열차카드·혼잡도시트·탑승세션 UI 전체 | 개인 키 발급 전까지는 참고용으로만 사용 |

## M1 포함 기능
- 2호선 시청~홍대입구 구간 실시간 열차 위치 (10초 폴링 + recptnDt 시차 보정 + 보간 애니메이션)
- 열차 카드: ~행 / 급행 / 열차번호 / 도착 카운트다운. **카드 탭 = 열차 선택(변경)**
- 하단 카드: 탑승 시작 버튼만 + 혼잡도 보기
- 칸별 혼잡도 시트 (통계 기반, 실시간 API는 M2)
- 탑승 위치(칸-문) 입력 시트
- 탑승 세션: 칩(진행형 알림) 상시 유지 → One UI 상태바 칩/Now Bar 승격,
  칩 탭 → 중앙 확장 카드, 1정거장 전 진동 + 문 방향/계단 방향 알림(하차까지 유지)
